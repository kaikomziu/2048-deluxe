# 2048 DELUXE

実績システム・レベル/XP・コンボボーナス・デイリーチャレンジ・6種のテーマ切り替えを詰め込んだ、おしゃれな2048風スライドパズルゲームです。

- サーバー不要・外部通信なしの純粋なHTML/CSS/JSのみで動作します。
- 進行状況(スコア・実績・テーマ解放状況など)はブラウザのローカルストレージに保存されます。
- PC(矢印キー / WASD)・スマホ(スワイプ)の両方に対応したレスポンシブデザインです。

## 遊び方

`index.html` をブラウザで開くだけで遊べます。GitHub Pagesでも公開しています。

## 主な機能

- 実績27種・レベル/XPシステム・連続マージのコンボボーナス
- 日替わりシード固定の「デイリーチャレンジ」
- 1ゲーム3回までのUndo
- クラシック / ネオン / パステルドリーム / ミッドナイト / サクラ / レトロアーケード の6テーマ(プレイして解放)
- ゲーム内フッターに更新履歴(バージョン・日付)を表示

## 開発

変更を加えたときは `script.js` 内の `CHANGELOG` にバージョンと日付を追記してください。
